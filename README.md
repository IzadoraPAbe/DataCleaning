## Start Here

This repository contains beginner-friendly examples of data wrangling and cleaning using Pandas. It covers common tasks involved in preparing real-world datasets for analysis, such as handling missing values, removing duplicates, correcting data types, standardizing values, filtering data, and transforming columns.

The examples are designed to demonstrate practical techniques that can be applied to different datasets and data analysis workflows.

---

## Datasets Used

The examples in this repository use a variety of datasets to demonstrate different data cleaning and wrangling scenarios.

| Dataset | Description |
|---|---|
| `athletes.csv` | Information about athletes who participated in the **2024 Paris Olympics**. |
| `medals.csv` | Data on medals won during the **2024 Paris Olympics**. |
| `amazon.csv` | A fictional dataset containing **Amazon sales and transaction information**. |
| `gym_members_exercise_tracking.csv` | Data related to **gym members, exercise routines, and fitness activity over time**. |
